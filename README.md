# Samu

Samu by Mahasamuha is a personal voice assistant for Android that replaces Google Assistant on a single Pixel phone. The app holds the default assistant role, so a power-button long-press or corner swipe opens its panel. It listens with on-device speech recognition, sends the question to a hosted LLM (Anthropic's Claude), and speaks the answer with on-device text-to-speech. Live answers come from tools: web search (Brave Search API) and weather (Pirate Weather) served by a small MCP server, and tools on the phone for contacts, calls, and texts, each confirmed or announced before it acts. Requests go through a small self-hosted auth gateway that checks identity-provider tokens and forwards to a private LLM gateway (Bifrost) that enforces a spend budget, so no provider keys ever live on the phone. See `docs/plan.md` for the design and its rationale.
